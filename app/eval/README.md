# 背题宝数据集与评测

当前版本为 `synthetic-v1`。原卷、题目和参考答案为项目内编写的合成样例。开发集可用于调试；合成评测集用于可重复的回归检查，其标签可在本地查看。真实盲测集须独立存储和授权。

| 集合 | 文件 / 标注题 | 用途 |
|---|---:|---|
| [开发集](data/development.json) | 2 / 2 | 文字型 PDF、单选和数值题，用于接口、提示词和解析调试 |
| [合成评测集](data/evaluation.json) | 4 / 4 | 多页 PDF、选项、主观题、数值题、纯图片页和损坏文件，用于回归 |
| 真实盲测集 | 待入库 | 验证实际学科、题型和材料质量，供发布门槛使用 |

[样卷文件](papers)中的 PDF 可直接用于 PC 试卷库。损坏文件专用于校验失败路径。源卷使用 `sourceGroup` 分组。工具检查同组、同 SHA-256 文件及重复题目 ID 是否跨集，以及每道题是否能回指有效来源页。正式样本还需人工检查裁剪、重排、改写和同题异版等近重复。PDF 再生成会受 Poppler 版本影响，基线比较以提交的样卷及报告中的 SHA-256 为准。

## 本地评测

从 `app/` 目录运行，使用 Node.js 和 Poppler。解析评测直接调用应用使用的 `extractPages`，输出逐卷 JSON，检查处理状态、页数、指定页面的文字片段和纯图片页的空文本路径。失败返回非零退出码。当前评测集 13/13、开发集 8/8。纯图片页的通过条件是保留页数并进入人工核对，视觉识别效果单独评估。

```bash
npm run eval --silent -- parse evaluation
npm run eval --silent -- parse development
```

解答评测先导出输入，再让被测系统逐题作答。输入包含题目文本，适用于单独衡量解题；视觉评测应从 PDF 原页生成模型输入。标准答案和主观评分点留在对应清单中。答案文件需包含 `datasetVersion`、`split`、`runId` 和 `answers[{id,answer}]`。runId 对应模型快照、提示词版本和参数。客观题做归一化后按接受答案精确计分，漏答计入分母。主观题有输出时标记为人工复核，由评审按评分点判定。

```bash
npm run eval --silent -- inputs evaluation > /tmp/beitibao-eval-inputs.json
npm run eval --silent -- answers evaluation /path/to/candidate-answers.json
```

## 真实样卷入库与发布评测

1. 收集获准评测的真实中文样卷。记录授权范围、来源、原卷版本、脱敏状态、科目、题型、页码、材料质量和扫描或拍照方式。个人身份和机构敏感字段在入库前脱敏。
2. 先做原卷、相近题与共用材料分组，再划分开发集和盲测集。盲测标签只供评审使用。按卷冻结文件哈希、标注版本及分组清单，并保留可审计的授权记录。
3. 每道真实题由学科评审标注题干、选项、公式、原页与区域、参考答案或评分点。跨页题记录全部来源页。至少复核答案及图表、公式和题目边界，分歧交由评审裁定。
4. 按任务出报告。识卷报告题目边界、选项、关键公式与源位置。解题报告分层正确率、关键步骤、人工复核和拒答。预测卷用冻结的同科材料出题，核查引用、可解性和答案。真实命中需另有获准的考后试卷用于盲测。
5. 发布仍按[架构门槛](../../docs/bmad/architecture.md)执行。首轮待补真实中文印刷卷、手机拍照、复杂公式、图表和跨页题。同学科同题型的放行层初始至少 100 题，预测至少 30 套证据集并人工复核。合成回归通过只能支持工程验证。

正式评测报告记录样本量、模型快照、提示词版本、通过率、人工复核量、处理时间、Token 和实际费用。真实样卷和盲测答案留在受限环境。

已见试卷的模型质量回归见[本机模型对比与逐项验收](local-model-pilot/README.md#严格超过-95-的复测)。所有模型质量指标按各自分母逐项判定，恰好 95% 不通过。预测卷的历史合成题复核与独立预测盲测分开记录。

## 图片识别修订样本

[用户图片上传校验](image-upload-validation.md)记录了新版真题逐页上传、PC 和窄屏浏览器操作，以及授权图题的百炼实测。

用户逐题确认、修订或标记误识别时，系统保存源图片指纹、模型及提示词版本、原始识别题干、修订题干和审核结论。经授权后，可按账户导出审核队列。在 `app/` 目录运行，使用受限应用数据库角色。

```bash
node eval/export-recognition-feedback.mjs ACCOUNT_UUID > /private/path/recognition-feedback.json
```

导出的记录可用于人工复核、分析高频错误、改提示词及构建回归集。按 `sourceGroup` 与 `sourceSha256` 对齐源图片，整张图片进入同一数据分组。将修订样本用于提示词调试时，从发布盲测集中排除同源样本。导出文件可能含用户题干，保存到受限目录并在跨账号合并前取得授权和脱敏。当前接入模型的优化路径是更新识别提示词与评测回归，模型权重更新需要另行选型及验证。

## 首批试卷适配与入库门槛

适配范围为大学所有采用纸笔考试的课程。以下三科属于当前合成回归批次。数据结构覆盖算法与伪代码，线性代数覆盖矩阵和多行公式，大学物理覆盖图示、单位和公式。三科均应包含电子原卷、扫描或手机拍摄试卷。适配验收以授权真实样卷与实测结果为准。

每科需要至少 **50 份测试卷和 5 份独立评测卷**，首批共 165 份。测试卷用于流程回归与调试，评测卷冻结后用于发布验收。同一原卷的扫描、拍照和改版按一个来源组计数。现有合成样例继续用于工程回归，正式样本统计从授权真实原卷入库起算。

正式清单保存在受限目录。JSON 顶层字段为 `papers`，每项记录 `subjectId`、`split`（`test` 或 `evaluation`）、`origin`（`real`）、`authorizationRef`、`sourceGroup`、`file` 和 `sha256`。评测卷另需 `goldFile`，包含 `questions` 数组，每题记录原页 `page`、题干 `stem` 和可接受答案 `acceptedAnswers` 或主观评分点 `rubric`。文件路径相对于清单。入库评审负责核查授权、整卷完整性和标注正确性。

在 `app/` 下运行 `node eval/check-subject-coverage.mjs /path/to/manifest.json`。检查器按科目报告缺口，验证文件哈希、来源组和评测标签。任一科未达门槛时返回非零退出码。省略清单路径可查看全部待入库的额度。

## 已保存的试卷与链路验证

[测试卷清单](subject-corpus/test/manifest.json)和[评测卷清单](subject-corpus/evaluation/manifest.json)与各自的 gold.json 保存在同目录。数据结构、线性代数和大学物理各有 50 份合成测试卷和 5 份合成评测卷，每卷 3 道题，评测采用不同题型模板。

## 真实原卷首批配对

本机 `source-materials/real-pilot/` 已保存数据结构、线性代数和大学物理各 1 套真实考试测试卷、1 套真实考试评测卷，以及 3 份单独的答案或评分参考。该目录的 manifest.json 记录卷别、学校、学期、原始下载地址、页数、哈希和答案文件。六套卷均通过本地 PDF 提取和页数检查。答案文件供评审对照，结构化评分标注和使用授权另行核验。全课程采集范围及每课发布样本门槛见[覆盖与采集](university-paper-exam-scope.md)。

从 `app/` 运行以下命令复验真实样卷。脚本校验文件哈希、内容重复、上传大小限制、卷与答案的对应关系及页数，并使用应用的渲染器检查试卷每一页。报告列出文本提取为空的页和授权状态。该检查在本地运行，输出仅包含文件元数据，结果用于评估文件能否进入识卷链路。

```bash
npm run build --silent && node eval/run-real-pilot.mjs
```

三套真实评测卷的[逐题标注与评测记录](source-materials/real-pilot/annotations/evaluation-report.md)保存在本地。

## 官方开放课程候选卷

`source-materials/ocw-candidates/manifest.json` 记录 MIT OpenCourseWare 的三套期末卷与答案，包含资源页、PDF 地址、页数和 SHA-256。6.006 用作算法与数据结构样本，8.012 用作大学物理经典力学样本，两门课的覆盖面按原课程记录。三套材料适用 CC BY-NC-SA 4.0，暂列为候选。背题宝的产品验收需要核对本次评测的用途是否符合非商业条款，或获得覆盖产品评测及外部推理的补充许可。[MIT OCW 使用条款](https://ocw.mit.edu/pages/privacy-and-terms-of-use/)

线性代数另有胡安卡洛斯国王大学教师发布的 CC BY-SA 4.0 历年期中题及解答汇编，已在同一清单单列。汇编尚未核验可还原为某次完整考试，因此未计入整卷。[大学原始发布文件](https://burjcdigital.urjc.es/server/api/core/bitstreams/8243c694-89c9-4ced-9668-cd783327d6ad/content)

补充核验发现肯塔基大学 CS315 2021 春季期末原卷（CC BY 4.0）和胡安卡洛斯国王大学 2025 年 5 月 12 日数据结构考试的教师解答版（CC BY-SA 4.0）。前者缺可核验的同卷官方答案，后者的发布源文件已经嵌入答案，缺独立学生原卷。两者属于不同考试，分别列为候选。大学物理另核查了俄勒冈州立大学 BoxSand 真题档案和格罗宁根大学 2022-04-04 试卷。BoxSand 公开开放资源声明限非商业用途，未发现该试卷档案的单独商业许可；格罗宁根文件只有第 4 题及其答案另授 CC BY-SA 4.0，整卷仍有非商业限制。当前没有向外部模型发送候选材料。

[真实试卷解析评测集](data/national-exams.json)纳入留出的 7 份 2025 年全国统考卷和 19 份 2026 年南京审计大学自命题卷，共 100 页。管理类综合仅保留源文件第 1–15 页，英语（二）仅保留第 1–13 页。两份评测副本的题页渲染与原 PDF 对应页一致，附录答案留在源文件。408 参考答案仍单独保存在档案中。清单记录每份评测输入的 SHA-256、页数和预期无文字层的页面。

从 `app/` 运行以下命令。评测检查应用解析状态、页数、图像页文本路径及每页能否渲染。逐题答案和评分标注、使用授权仍待核验。本集合用于本地整卷解析回归。

```bash
npm run eval --silent -- parse national-exams
```

在 macOS 上运行 `bash scripts/test-local.sh --national-full` 可复验全档案和留出集。检查所有归档 PDF 的哈希、页数与卷答配对，使用隔离数据库跑完整的上传、解析、逐页预览及扫描队列。本机 Apple Vision 为扫描页记录文字返回量。程序只保留计数、命中标记和文件元数据，逐题准确率需要独立标注才能计算。
