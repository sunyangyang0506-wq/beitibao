## 逐项验收

题号与来源页匹配、选项齐全、题干文本一致、选项文本一致、印刷页码正确、与官方答案一致，以及本轮各解题模型的正确率，分别要求严格超过 95%。整卷题目指标以 40 题为分母，38/40 不通过，至少需 39/40。印刷页码以 4 页为分母，需 4/4。分模型按能与官方答案对照的题计分，漏题或漏题号计入整卷分母。没有实际模型用量的报告无法通过验收。

逐页对照原图后，参考文本修正了第 13、17、36、38 题的 A 选项边界，并还原第 13、14、20、25 题的公式上下标。评分要求数字题号后有分隔符，同页重复题号计为未匹配。官方答案与全半角、空白归一化规则沿用原版。旧报告保留，复算另存 `-audited-score.json`。[原图](trial-question-pages.pdf) · [复核后的参考文本](official-exam-2020-gold.json)

`v20` 复算的题号与来源页匹配、选项齐全均为 39/40，印刷页码 4/4。题干文本 35/40，选项文本 34/40，解题 27/40。文本 Flash 答对 22/33，视觉 Flash 答对 5/6。修订分数来自对同一批输出的复算。[逐题复算](official-exam-2020-v20-20261110-audited-score.json)

新版要求按原字形、公式和代码缩进转录。完整的文本单选由带推理的 Plus 作答，服务端核对答案字母与选项正文。新版通过本地回归，仍待真实整卷复测。北京业务空间接入点拒绝调用，同一 API Key 在北京通用接入点返回 `Arrearage`。[百炼欠费错误说明](https://help.aliyun.com/zh/model-studio/error-code-start#arrearage)
