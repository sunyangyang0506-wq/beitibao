# 408 真题批量上传与识别实测

测试开始于 2026 年 11 月 8 日 20:19:12（北京时间）。选用之前选择的 2014 至 2023 年 408 真题 PDF，共 10 套、81 页、43,270,077 字节（约 41.27 MiB）。

在独立本机测试账号和科目下，通过与 PC 上传页相同的本地 API 双路提交。计时从发出请求开始，文件预读和文件选择不计入。10 份均获得独立试卷 ID，均未命中重复上传。

10 套上传归档通过 5 分钟验收。识别任务在本轮收尾时仍有失败和缺失页码的页面。未以这次本机测试推断外网耗时。

复测沿用相同的 10 套 PDF 和 81 页，关闭了结果复用。本机页面识别并发由 4 提至 6，并在模型 JSON 输出异常时尝试一次宽松 JSON 输出。复测约 82 秒进入终态，但当日可用模型预算不足，最终只有 42 页成功，39 页失败。这个时长不能用来比较完整批次的速度。

上一轮失败的 2014 年第 2、3 页和 2017 年第 3、5 页在复测中成功返回。对照原卷检查了 2014 年第 2 页和 2017 年第 3 页的印刷页码与新题号。2017 年该页开头的上一题续文被误分为独立题，随后加入了针对页首续文的规则和回归用例。复测只支持上述样本结论，尚未测得新版完整批次的识别准确率和耗时。
