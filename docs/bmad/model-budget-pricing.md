# Plus 思考模式费用预算修复

核验日期：2026-11-10。此修复针对现有北京百炼实时调用，不代表已核对账户实际账单或已部署。

## 价格与用量口径

[阿里云 qwen-plus 官方说明](https://help.aliyun.com/zh/model-studio/qwen-plus)中，`qwen-plus-2025-12-01` 的华北2（北京）、输入不超过128K档：输入0.8元、非思考输出2元、思考输出8元，单位均为每百万Token。这里使用快照型号对应的北京价格，不套用其他地域、Batch、免费额度或折扣。现有网关32,000输入Token预占落在此档内。

[OpenAI兼容Chat API说明](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)对应当前工作空间北京端点。`completion_tokens` 是全部输出用量，`reasoning_tokens` 是输出细分，结算时不能再加一次。该快照使用 `max_tokens` 限制回答、`thinking_budget` 限制思考，因此保留现有两者相加的输出预占方式。[深度思考说明](https://help.aliyun.com/zh/model-studio/deep-thinking)确认旧Plus系列默认不启用思考；省略 `enable_thinking` 仍走非思考价格。

## 修改与影响

- 按请求是否启用思考选择Plus输出单价；同一个单价同时用于请求前预占和可信usage结算。
- `enable_thinking` 若给定，必须是布尔值，避免网关和供应商对字符串或数字的解释不同。
- 不改模型、提示词、token预算、并发、日预算配置或其他三个模型的现有单价。
- 选择题解答的3400回答+1600思考上限，预占从35,600增至65,600微元；预测生成的700+1600上限，从30,200增至44,000微元。1元=1,000,000微元。
- 100输入、200总输出的思考调用，费用估计从480改为1,680微元；不是把所有调用总价乘四，只有输出单价变化。
- 可信费用会释放预占、写入全站和租户已花费；超时或不可信用量继续保留修正后的预占。既有402处理不变。

## 边界

这不是历史账单回填：已有调用未保存思考模式与价格版本，不能仅凭模型ID准确重算。未改历史记录或日预算。

32,000是现有网关的输入预占假设，并非本修复新增的实际输入Token硬上限。返回用量超出该范围仍标记unknown并保留预占，不能保证覆盖任意超长输入的实际费用。启用更大输入、其他模型或新计费功能前应另行验证；实际费用以供应商账单为准。

所有本次测试使用合成usage、测试替身或隔离数据库，不调用收费模型。持久化、原生数据库与独立审查结果另见交付报告。
