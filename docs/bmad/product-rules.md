# 背题宝 PC 端产品规则

学员端和账号管理后台均只支持笔记本电脑浏览器。规则以最新用户批注为准，覆盖旧需求中关于上传前选科、用户逐页核对、选择题大输入框和错题日期口径的描述。下文区分目标行为、原型演示和实测结果。编号可用于开发任务、测试用例和验收记录。

## 1. 账号、学科与首次使用

| 编号 | 规则与验收 |
| --- | --- |
| ACC-01 | 管理员输入学员手机号和学科上限生成邀请码，经已有联系渠道交给学员。邀请码绑定手机号、24 小时有效、仅成功注册一次，后台显示待使用、已使用、已过期。手机号不匹配、邀请码错误或失效时给出可操作的提示。重复注册引导登录。 |
| ACC-02 | 学员通过「接受邀请」输入手机号和邀请码，自行设置密码，之后使用手机号和密码登录。历史邮箱账号兼容原登录方式，后台可用手机号或旧邮箱查找。发码、查找、改上限均由服务端验证管理员身份，邀请码只在签发时展示，服务端保存摘要。 |
| ACC-03 | 学科按账号内规范化名称计数。同名科目跨学期仅占一门，课程及其试卷、进度、预测仍按具体学期分别管理。上限下降时已有科目和历史照常使用。达到或超过上限时拦截新增不同名称的科目，录入和自动归档走同一校验。并发添加不得突破上限。 |
| ACC-04 | 学员可添加科目，名称和学期必填，教师选填。重复添加同一课程时引导打开已有课程。同名跨学期允许添加。验收覆盖上限为 2 门时能添加第二门「大学物理」、拦截第三门「大学英语」，调回 1 门后已有两门仍可用，调到 10 门后可添加 2027 春「高等数学」，该同名科目不新增学科名额。 |
| ACC-05 | 付款和账号开通独立。后台可直接发放邀请码、配置学科上限，学员激活不依赖支付状态。 |
| ONB-01 | 首次登录的「学习进展」显示一个「上传试卷」入口，点击直接打开上传界面。纸卷先扫描为 PDF，再从笔记本电脑上传到试卷库，由模型识别。上传界面提供扫描指引，包含拍齐全部页面、避免反光和合成一份 PDF。试卷库始终提供上传入口。 |

## 2. 上传、归档与整卷识别

| 编号 | 规则与验收 |
| --- | --- |
| LIB-01 | 只接收 PDF，可一次选择最多 30 份，每份独立归档为一套卷，单份最多 30 页。单文件体积上限取部署配置，页面须展示实际生效值。逐文件校验类型、大小、页数、加密及损坏状态。某份失败时继续处理其他合格文件，展示成功项、失败原因及单份重试入口。 |
| LIB-02 | 正常上传流程只选 PDF 并确认材料使用权限。模型依据卷面标题、科目代码和题目内容识别试卷名称与科目。识别中暂用文件名。识别后显示卷名、归属科目和具体课程，唯一可靠匹配时自动归档。 |
| LIB-03 | 科目不明确、同名课程匹配到多个学期或无法匹配已有课程时，显示「待归属」、建议科目和下一步。用户可选择目标课程，或在额度允许时添加课程再归档。卷名未识别时保留文件名并提示识别结果。低置信结果不得静默覆盖已确认归属或卷名。 |
| LIB-04 | 保留 PDF 文件页序、卷面印刷页码与最终阅读顺序。印刷页码能够组成唯一可信序列时自动排序，封面等无印刷页码的页面按卷面结构定位。缺号、重号、模糊或冲突时保留原始页号及证据。仅在有可靠证据时判为缺页，页码无法读取不等同于缺页。 |
| LIB-05 | 模型提取卷首说明、题号、题型、题干、选项、公式、图表、共用材料、分值和来源位置。跨页题按题号与语义拼合，保留所涉页码。系统检查题号连续性、选项完整性、材料引用与跨页冲突，自动尝试修复和复核。正常卷自动进入「可练习」。 |
| LIB-06 | 同账号同归属的同一文件允许复用相同输入版本的模型结果。跨账号按「同校同科试卷复用」判定。上传和重试可安全重复执行，保留每份文件结果，过时任务不得覆盖较新的识别、归属或修订。 |
| LIB-07 | 试卷详情提供完整连续卷面的「原卷预览」与「试卷识别」。两侧按页、题号对齐并可互相定位。识别侧保留卷首、分区、题干、选项、图表和跨页顺序，封面无题时可继续浏览后续页。阅卷视图中已生成的参考答案直接填在对应题目旁，选择题填入题干括号，主观题在相应位置展示，解析和知识点可展开。显示答案来源、核验状态及未生成原因。 |

### 同校同科试卷复用

1. **确定查询范围。** 学员的已核验学校 ID 与共享版本的学校 ID 一致，科目映射到同一标准科目 ID，且共享授权仍有效。科目未确定时，可在该校已授权的索引中查文件或首页指纹。整卷命中且指向唯一标准科目时可直接带出科目。仅首页命中时先比对余页，仍无法确定科目时沿用识别流程，无法唯一归档时显示「待归属」。
2. **查找候选卷。** 服务端校验已上传的 PDF，并计算整文件 SHA-256。整文件相同可直接进入结果版本校验。整文件未命中时，把 PDF 文件的第一页按固定版本的渲染规则转换为整页像素并计算 SHA-256。第一页图像指纹相同即命中候选卷，已知科目时按同校同科筛选。第一页的题干、选项、公式、图表、页眉和页脚都参与比对。
3. **确认是否为同一套卷。** 候选卷与上传卷的总页数相同，且按文件页序逐页得到的图像指纹全部相同，即确认同卷。两份均为单页且历史版本已确认是完整试卷时，第一页相同即可确认同卷。多页卷只有第一页相同时，继续比对余页。页数或任一页不同则分为不同版本。有卷面缺页证据时显示「缺页」，原卷预览按学员实际上传的文件展示。
4. **按结果版本复用。** 同卷命中且历史识别、参考答案、知识点及解析均已就绪，通过质量校验且版本仍有效时，直接引用该共享版本，跳过对应模型任务，答案保留原来源及核验状态。部分命中时，只复用确认相同的页和完整题目。题干、选项及其顺序、公式、图表、跨页材料和适用评分依据都一致，才复用该题的答案与知识点。只处理未命中、缺失、失败或已失效的部分。
5. **处理并发与授权变化。** 同校已获共享授权的同一试卷版本只排一个相同版本的处理任务，后续上传者等待该任务结果。直接复用时显示「已复用同校同科试卷解析」，学员各自拥有归档、作答和进度。共享版本停用、撤回授权或被纠错替换后，从可复用索引移除。

| 验收样例 | 预期 |
| --- | --- |
| 同校同科，两份 4 页卷的第一页完全一样，后 3 页也逐页一致 | 确认同卷。可用的原卷识别、答案、知识点和解析全部复用。 |
| 同校同科，两份 4 页卷的第一页完全一样，第 3 页有一个选项变化 | 分开归档。复用输入完整且一致的题目，第 3 页变更题及依赖它的题重新处理。 |
| 同校同科，第一页完全一样，但一份为 4 页，另一份为 3 页 | 保留为不同版本。有卷面缺页证据时显示「缺页」。 |
| 同校同科，两份均为完整单页，第一页完全一样 | 确认同卷，直接校验历史结果是否可用。 |
| PDF 完全相同，但学校不同、学员未核验或共享授权已撤回 | 按账号内原有流程处理。 |

### 试卷列表状态与下一步

| 状态 | 判定 | 下一步 |
| --- | --- | --- |
| 识别中 | 文件已归档，题干与页序仍在处理或自动复查 | 查看进度，可离开页面后返回 |
| 待归属 | 科目结果不足以唯一匹配课程 | 选择课程或添加课程后归档 |
| 待核对 | 自动复查后仍有影响使用的题干、选项或图表疑点 | 查看具体问题，重试相关页或更换清晰 PDF |
| 暂无可练题 | PDF 已归档，当前无可练题和待核对页 | 查看识别状态及原卷，按来源页手动补录题目 |
| 缺页 | 有可靠证据表明原文件缺少试卷页面 | 查看疑似缺失范围，上传完整 PDF |
| 识别失败 | 文件或识别任务失败，当前无法产出可用结果 | 查看原因，按原因重试或重新上传 |
| 可练习 | 卷面已具备作答条件，存在自动确认或手动补录的题目 | 开始练习，未就绪的答案单独显示生成状态 |

单卷显示一个主状态，并保留具体页和任务异常。题干识别、原卷解析和预测卷各自有进度。原卷已可练时，单道解析仍在生成不会把整卷重新标成「识别中」。

## 3. 模型答案、知识点和试卷分析

| 编号 | 规则与验收 |
| --- | --- |
| AI-01 | 可用题干通过自动校验后，后台自动生成参考答案、解析和知识点，并根据当前课程的可用原题同时触发预测卷任务。生成答案无需等待预测，预测也不以原卷全部答案生成作为前置条件。若有缺失图表、选项或条件，标明具体缺项。 |
| AI-02 | 客观题给出参考选项或填空值及理由。计算题给出条件、关键步骤、结果和适用单位。简答、论述、综合题给出参考作答和评分要点。判分优先使用教师提供或已核验的答案，也可使用能明确比较的模型参考答案。证据不足时显示「无法自动判定」。 |
| AI-03 | 每次揭晓答案时同屏展示该题直接考查的知识点及对应步骤或要点。证据支持时补充先修与同题共现。知识点、答案、解析分别展示就绪状态，支持对失败任务重试。 |
| AI-04 | 原卷交卷后展示逐题解析、整卷知识网及出题逻辑，覆盖未答题。知识网节点能跳到关联题，区分先修、同题共现、综合应用。出题逻辑说明题型分布、知识点组合和考查层次，结论可追溯至原题，区分卷面观察和模型归纳。 |
| AI-05 | 每份作答结果绑定题干、图表和答案版本。同输入版本的迟到解析可补齐。题库后续修订不改写历史结果。个人答案和解析修订独立保存，可恢复模型原文。实质性题干变化触发对应题目重新练习，仅更改答案保留覆盖并复查相关判分。 |

## 4. 题目背诵与交卷

| 编号 | 规则与验收 |
| --- | --- |
| PRA-01 | 提供「整套答题」和「按题型背诵」。整套先选科目和原卷，按真实考试卷面连续展示全部题目，保留分区、说明、题号、材料和已知分值。右侧答题卡按题型分组，显示已答、未答和标记，可跳题。 |
| PRA-02 | 选择题作答直接写在题干括号内，可用键盘输入或点击选项，无可识别括号时在题干末尾补一个。单选只接受一个有效选项，多选接受有效选项组合。移除选择题大输入框和整套作答区的「纠正题干」入口。填空题在空位输入，计算、简答和综合题使用可书写步骤的文本区。 |
| PRA-03 | 整套闭卷开始时答题位置为空，题目答案、知识点、解析、知识网和泄题材料在页面与接口均隐藏。模型参考答案于交卷后在卷面对应位置展示，与学生作答分别标注。学员可在揭晓后保存自己的答案或解析。 |
| PRA-04 | 自动保存答案、标记和最近位置，刷新或重新进入可继续。显示保存中、已同步、同步失败与重试。限时按原卷时长或开始前设置的时长，均未设置则不限时。服务端截止时间在刷新后保持，到期提交已同步答案，提示未同步修改是否计入。 |
| PRA-05 | 全卷统一提交，先显示未答数量，可返回补答。重复提交使用同一答卷。交卷结果、进度及错题收录一致写入。结果区区分判对、判错、未答和无法自动判定，已判错题可直接进入重练。模型解析仍在处理时先展示已有结果。 |
| PRA-06 | 专项配置顺序为科目 → 题型 → 试卷。题型仅来自当前科可练题。默认选中匹配卷，可取消，显示每卷题数和总题数。切换科目重置下游选项，切换题型刷新试卷，零题禁用开始。跨卷去重并保留全部来源。 |
| PRA-07 | 专项可先默背或作答，再逐题揭晓。自评为「能独立说出」「漏了部分」「还想不起来」。完成自评回写原卷覆盖，后两项自动加入错题本。仅打开题目、展开答案或保存草稿不增加覆盖。 |

## 5. 每科一套预测卷

| 编号 | 规则与验收 |
| --- | --- |
| PRE-01 | 每个具体课程展示一套当前预测卷。新原卷题干通过自动检查后，按同科同课程的可用来源自动生成或更新。跨账号复用须同时满足同校、同标准科目、同预测课程范围（教师或统一命题范围及目标学期）、去重后的来源卷内容版本集合一致、预测规则版本一致、旧预测卷已整套校验发布且仍可共享。来源集合使用共享内容版本标识，重复上传同一版本不改变集合。只要有来源卷新增、替换或撤回，就重新判定预测卷。学员不需要点击「生成」。并发上传合并同版本请求，旧任务不得覆盖新结果。 |
| PRE-02 | 依据去重后的可用来源题规划 5–12 题，组成有卷名、题型分区、完整题目和配套答案的一整套卷。来源少于 5 题时显示「来源不足」及补充入口，仅有一套来源标明「依据有限」，未覆盖内容标为未知。 |
| PRE-03 | 每道预测题具备题干、有效选项或完整条件、参考答案、解析、知识点、来源题和推演理由。客观和计算题复算，主观题复核题干、参考答案与评分点一致性。所有计划题通过后整套发布，未通过可自动替换或重试。失败时提示原因与重试入口，已有可用版本和历史作答可继续访问。 |
| PRE-04 | 预测卷使用整套作答流程，独立统计。交卷后提供逐题知识点、整卷知识网和预测逻辑，标明哪些是源卷观察、哪些是模型推演，可跳转对应证据原题。闭卷期间隐藏可能提示解法的证据。 |

## 6. 错题本与重练

| 编号 | 规则与验收 |
| --- | --- |
| ERR-01 | 联动整套原卷、预测卷和专项背诵。自动判错的题目和专项自评待巩固的题目进入「待重练」。重练时依据不足则显示「无法自动判定」。支持手动收录及取消手动收录，取消收藏不移除自动收录记录。 |
| ERR-02 | 默认展示全部状态和全部科目、题型、时间。状态含「全部」「待重练」「无法自动判定」「已重练」。科目、题型、错题时间和状态取交集。时间按北京时间，可筛选具体日期。无匹配时提供清除筛选。 |
| ERR-03 | 展示可切换为「按错题时间」「按题型」「按题型和错题时间」。时间分组按日期从新到旧，题型和时间模式先分题型、再分日期，分组显示题量。错题时间取最近一次判错或自评待巩固的发生时间，仅手动收录用其收录时间。保留首次收录历史。缺时间的旧记录在不限日期时归入「日期未记录」。 |
| ERR-04 | 详情展示科目、来源卷、题号、题型、错题时间、收录原因、当时的作答、参考答案、知识点和解析。单选、多选在原选项标明当时所选与参考选项，多选区分漏选与多选。填空逐空对比。计算题展示当时步骤、参考步骤和结果。简答与综合题对照评分要点，列出有依据的遗漏。 |
| ERR-05 | 同一题聚合一条记录并保留历次尝试。重练开始时隐藏旧作答和答案。正确或自评能独立说出后移至「已重练」，成功重练不改错题时间。再次答错则回到「待重练」并更新时间。源答案变更导致旧判定依据失效时显示「无法自动判定」。 |

## 7. 学习进展与考试时间

| 编号 | 规则与验收 |
| --- | --- |
| PRG-01 | 首页展示当前科目总数、背题完成数、尚未完成数。科目表支持全部、未完成、已完成，逐科显示已完成套数、总套数、剩余套数、预测入口和下一步。无卷科目显示上传入口，有草稿时优先继续。 |
| PRG-02 | 当前原题有效作答或完成专项自评才计入已练。单卷所有题可用且均已练才算完成。已确认同一版本的重复题覆盖其原卷出处。归档原卷计入总套数，异常卷计入剩余并注明状态。至少有一套原卷且全部完成才算科目完成。新增未完成卷后重新计算，预测卷单独统计。 |
| PRG-03 | 每个科目行提供「考试时间」入口。学员可按课程添加、修改和清空日期与时间，已设置时显示具体时间并可点击编辑。按北京时间显示，刷新后保留。同名不同学期分别保存。此字段表示学校安排的考试时间，模拟卷倒计时由练习设置决定。 |
