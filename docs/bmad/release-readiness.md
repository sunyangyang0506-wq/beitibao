## 本轮体验与发布验收补充

- 作答按修改自动同步，显示保存状态。到期以服务器接收记录为准，并提示未计入的修改。混合压测须使用新自动保存行为，记录实际写入速率，早期每 20 秒保存的估算不作为当前验收负载。
- 错题本支持按科目、题型、首次收录日及状态筛选。等价错题合并取最早有效日期。交卷页按错题、未答与待复核筛选，可直接重练已核验错题。
- 新交卷保存模型解析快照。同题干、同图表上下文的迟到解析可补齐一次。旧答卷缺少快照时保留原参考答案与成绩，页面提示历史模型解析不可用。
- 上传核对页显示可练题数和待核对页数。管理员后台显示最近 50 条邀请状态。
- 升级环境执行迁移 030，并重放 API 与定时交卷角色授权。跨账号隔离、闭卷泄题与 10,000 用户同时处理 100 套不同卷的云端验收继续作为放行条件。
