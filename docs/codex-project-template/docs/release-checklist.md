## 设计与产品

- [ ] 目标用户、入口、成功结果和范围已确认。
- [ ] 关键界面使用接近实际的内容，已核对桌面、移动端和窄屏。
- [ ] 加载、空态、失败、重试、成功与无权限状态按适用性确认。
- [ ] 键盘焦点、标签、对比度和错误提示已检查。
- [ ] 验收条件有明确目标、验证方式和负责人。

## 实现与集成

- [ ] 在测试环境从正常入口走通成功、失败、恢复流程。
- [ ] 构建、类型、静态分析及适用测试通过，附命令和结果。
- [ ] 既有调用方、历史数据、角色权限和租户隔离已核对。
- [ ] 重复请求、并发、超时、部分失败和重试按风险验证。
- [ ] 真实浏览器中的截图、操作记录与确认的设计一致。

## 数据、AI 与性能

- [ ] 数据来源、版本、字段规则、重复、缺失和样本对账已检查。
- [ ] 新增、更新、删除与权限变化按目标时间传播到缓存、索引和用户界面。
- [ ] AI 评测使用固定样本与评分规则，记录基线、候选配置、准确性、引用、无答案、权限和成本结果。
- [ ] 响应速度在约定设备、网络或负载下测量，记录环境、样本量、P95 和基线。
- [ ] 数据新鲜度单独测量，并对照需求目标。

## 发布前

- [ ] 独立验收完成，阻塞问题均有修复和复测证据。
- [ ] 候选提交、构建产物与部署环境对应，配置和依赖已核对。
- [ ] 适用的迁移在接近生产的环境演练，明确备份、恢复方式及预计耗时。
- [ ] 核心流程、错误率、延迟和新鲜度的观察入口已准备。
- [ ] 发布范围、观测窗口、回滚阈值、执行步骤及负责人已确认。

## 发布后

- [ ] 记录发布版本与时间，在生产入口执行适当的冒烟检查。
- [ ] 观察窗口内对照阈值检查指标、告警和关键数据变化。
- [ ] 触发回滚条件时执行预案，复核服务和数据是否恢复。
- [ ] 收集失败样例，记录后续事项并补入回归测试或评测集。
