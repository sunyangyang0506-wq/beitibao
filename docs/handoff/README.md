# 背题宝项目交接

交接核对日期为 2026-11-10，时间均使用北京时间。当前需求从已确认的决定和规则开始读，实际实现与上线状态分别查对应证据。

| 接手事项 | 入口 |
| --- | --- |
| 原始定义、PDF 批注、界面批注和设计图 | [产品原始资料](product-origins.md) |
| 最终决定、两份需求的差异、现有实现与缺口 | [决策与实现对照](decisions-and-coverage.md) |
| 真实试卷、题库、评测原始输出和本机部署材料 | [材料和恢复说明](materials.md) |
| 北京预发、域名、模型开关和最近验收 | [云端状态](cloud-state.md) |

接手开发时使用 [产品规则](../bmad/product-rules.md) 的规则编号和 [决策与实现对照](decisions-and-coverage.md) 的证据列。旧版 [PRD 1.7](../bmad/prd.md) 保留原始需求、验收用例和设计参考。测试、回归、独立盲测和预发实测分别记录。
